# Rechtspraak Schenk- en Erfbelasting

Openbaar, automatisch bijgewerkt overzicht van rechtspraak over schenk- en
erfbelasting (Successiewet 1956). De pagina wordt gegenereerd uit de rechtspraak
Open Data API en wekelijks ververst.
